# GAAPICommon

The public moNitrav API for Agents, Jobs, Licence, Maps, Scheduling and Servicing.
Implemented in gRPC https://grpc.io/ - this package contains the required proto files for clients. 

Version 2.6.1 => This version is compatible with the latest v1.0.x release of moNitrav.  
Version 2.7.0 => This version is compatible with the latest v1.1.x release of moNitrav.
